# Delta

Jeu de précision (couleur, fréquence, tracé, forme, mélodie). Ce dépôt publie :

- sa page d'accueil, https://maxmoniot.github.io/delta/ — le lien que le jeu met dans les scores partagés : sur un téléphone
  Android, elle envoie directement vers Google Play ; sur un iPhone ou un iPad, vers la version iPhone ;
- la version iPhone et iPad, https://maxmoniot.github.io/delta/jouer/ — le jeu, à ajouter sur l'écran d'accueil depuis Safari
  (Partager › « Sur l'écran d'accueil »), qui se joue ensuite en plein écran et sans connexion ;
- ses [règles de confidentialité](https://maxmoniot.github.io/delta/confidentialite.html).
