# Delta

Jeu Android de précision (couleur, fréquence, tracé, forme, mélodie). Ce dépôt publie sa page d'accueil,
https://maxmoniot.github.io/delta/ — le lien que le jeu met dans les scores partagés : sur un téléphone Android, elle
envoie directement vers Google Play — et ses [règles de confidentialité](https://maxmoniot.github.io/delta/confidentialite.html).
